Доверять серверу Aster

Сервер Aster в локальной сети шифрует связь своим сертификатом. Браузер его пока не знает и пишет «Подключение не является приватным». Поставьте сертификат сервера в доверенные — один раз на каждом компьютере и телефоне. После этого предупреждение пропадёт.

Скачать сертификат

Сверьте отпечаток (SHA-256) — в свойствах сертификата он должен быть таким же:

@FP@

Windows (Chrome, Edge, Яндекс Браузер)

  1. Скачайте сертификат и откройте файл aster-ca.crt.
  2. Нажмите Установить сертификат… → Текущий пользователь → Далее.
  3. Выберите Поместить все сертификаты в следующее хранилище → Обзор → Доверенные корневые центры сертификации → Далее → Готово.
  4. В предупреждении системы нажмите Да.
  5. Закройте браузер полностью и откройте https://@HOST@.

Или одной командой в PowerShell (права администратора не нужны, система спросит подтверждение):

iwr http://@HOST@/aster-ca.crt -OutFile $env:TEMP\aster-ca.crt; Import-Certificate -FilePath $env:TEMP\aster-ca.crt -CertStoreLocation Cert:\CurrentUser\Root

Firefox на Windows обычно берёт сертификаты из системы. Если всё равно предупреждает: Настройки → Приватность и защита → Сертификаты → Просмотр сертификатов → Центры сертификации → Импортировать.

Android

  1. Скачайте сертификат на телефон.
  2. Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС → выберите aster-ca.crt. (Названия пунктов зависят от телефона — поищите в настройках «сертификат».)

iPhone, iPad

  1. Откройте эту страницу в Safari и скачайте сертификат → Разрешить.
  2. Настройки → Профиль загружен → Установить.
  3. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите «Caddy Local Authority».

Этот сертификат подтверждает только сервер Aster в вашей сети. Ставьте его, только если скачали со страницы http://@HOST@/trust и отпечаток совпал.
