# Почта агентов

Координатор пишет задания в tasks/<агент>/. Агент читает конкретное задание и пишет отчёт в results/<агент>/ с тем же номером. Задания и чужие отчёты не редактировать.

Раунд 001 — аудит. Новые поручения получают следующий номер; старые файлы сохраняются. Агент не начинает следующее задание без явного поручения.

После завершения агент сообщает пользователю статус, полный путь отчёта и главные блокеры. Пользователь передаёт путь координатору в чат. Автоматического наблюдения за папкой нет.

Файл отчёта — источник подробностей; сообщение «готово» без отчёта недостаточно. При блокировке тоже создать отчёт. Черновик сохранять как 001-report.draft.md, законченный отчёт — 001-report.md.
