# Приёмка координатора — 2026-11-09

Принят частично как анализ документации. Сервер и откат не проверены. Команды из отчёта не считать готовой инструкцией для PowerShell.

Подтверждено чтением ops/Caddyfile: локальная конфигурация использует /srv/aster. Это не доказывает конфигурацию запущенного сервера. ops/deploy.sh:19 применяет rsync -a --delete.

Уточнения:
- rsync --delete удаляет лишние файлы назначения, не обязательно всю предыдущую версию. В handoff команда без --delete; неизвестно, какая реально выполнялась. Утверждение «предыдущая версия физически удалена» не доказано.
- Отсутствие локального архива не доказывает отсутствие серверных архивов/снимков. Статус предыдущего артефакта: неизвестен, а не установленно отсутствует.
- Команда с $(date ...) внутри двойных кавычек PowerShell выполняет подвыражение локально. Не запускать её как написано. Следующая инструкция должна явно разделять оболочки и фиксировать конкретный путь копии, без wildcard rollback-*.
- /tmp, sha256sum и curl без .exe не являются переносимой инструкцией для текущего Windows PowerShell. Нужны команды под фактическую оболочку.
- Список ассетов получать из проверяемой сборки, включая динамические чанки. Имена старой сборки не универсальны. Не скрывать stderr; проверять HTTP-код, тип ответа и содержимое: SPA fallback может вернуть index.html вместо отсутствующего JS.
- curl -k отключает проверку подлинности сервера. Для подтверждённой проверки использовать доверенный CA; -k допустим лишь как явно ограниченная диагностика.
- Происхождение сборки может подтверждаться воспроизводимым процессом и метаданными, не обязательно тем же исполнителем. Оно не является принципиально нефиксируемым.

GLM пока ожидает. Исполнение проверок сервера и конкретный сценарий сохранения/отката готовит координатор после готовности QA. Никаких deploy/restore этим отчётом не выполнено и не разрешено.
