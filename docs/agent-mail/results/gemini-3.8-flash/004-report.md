## 1. Анализ унаследованного состояния от Luna

1. **Исходный код `web/src/pages/ContractsDashboard.jsx`**:
   - `scalar = v => v && typeof v === 'object' ? (Array.isArray(v) ? (v[0] ? scalar(v[0]) : '') : (v.name ?? v.title ?? v.id ?? '')) : v`
   - **Ошибки**:
     - Брал только первый элемент массива `v[0]`, отсекая остальных подрядчиков при множественных связях.
     - Для родительского договора клик делал `onOpen?.(Number(scalar(value(r, c.parent))))`. Если `parent` — объект `{ id: 10, name: 'X-1' }`, `scalar` возвращал `'X-1'`, а `Number('X-1')` давал `NaN`.
2. **Исходные тесты `web/src/pages/ContractsDashboard.test.jsx`**:
   - `parent` задавался как объект `{ id: 10, name: 'X-1' }` вместо формы API `[{ id: 10, name: 'X-1' }]`.
   - Селектор `getByRole('button', { name: 'X-1' })` был неоднозначен (дублировался кнопкой в колонке номера договора).
   - Проверка `queryByRole('button', { name: /Y-/ })).not.toBeInTheDocument()` падала из-за наличия кнопок номеров документов и баров диаграммы с именами `Y-1`, `Y-2`.

## 2. Собственные изменения

### 1. `web/src/pages/ContractsDashboard.jsx`
- Добавлен хелпер `label(v)`:
  - Корректно форматирует массивы объектов связей через запятую (`ООО Альфа, ООО Бета`).
  - При пустых значениях/пустых массивах выводит `—`.
- Добавлен хелпер `linkTarget(v)` для родительских ссылок:
  - Извлекает объект ссылки (поддерживает и одиночный объект/число, и массив из одного элемента формы API `[{ id, name }]`).
  - Проверяет валидность `id`: строго положительное конечное число `Number.isFinite(id) && id > 0`.
  - При `id <= 0`, `NaN` или нечисловых значениях возвращает `null` (ячейка рендерит `'—'` без кнопки).
  - Заголовок кнопки берёт из `item.name ?? item.title ?? String(id)`.
- В таблице реестра:
  - Колонка «Подрядчик» форматируется через `label(value(r, c.contractor))` — отображаются все связанные контрагенты.
  - В карточке просроченных документов подрядчик форматируется через `label(value(x.rows[0], c.contractor))`.
  - Колонка «Родительский договор»: при валидном `parentTarget` рендерит `<button className="contracts-link" type="button" onClick={() => onOpen?.(parentTarget.id)}>{parentTarget.title}</button>`, иначе `'—'`. Вызов `onOpen` с `0`, `NaN` или строкой имени полностью исключён.

### 2. `web/src/pages/ContractsDashboard.test.jsx`
- Устранены неоднозначности селекторов: поиск ограничен конкретной строкой таблицы через `within(rowsFound[i])`.
- Протестирована реальная форма API `parent: [{ id: 10, name: 'X-1' }]`:
  - Проверка вызова `onOpen(10)`.
  - Проверка отсутствия вызовов `onOpen(0)` и `onOpen(NaN)`.
- Добавлены проверки невалидных и граничных значений `parent`:
  - `parent: null`, `parent: ''`, `parent: [{ id: 'invalid', name: 'Broken' }]`, `parent: [{ id: 0, name: 'Zero' }]`.
  - Проверено, что во всех этих случаях ячейка показывает `—` и не содержит интерактивной кнопки.
- Проверено отображение нескольких подрядчиков через запятую (`ООО Альфа, ООО Бета`) и пустого подрядчика (`—`).
