## 4. Разделение понятий: «НПВ» vs «Отказ»

В базе данных и бизнес-процессе APS чётко зафиксированы два разных понятия:
1. **НПВ (Нерукотворное / Непроизводительное время / NPT)**:
   - Любое время задержки выполнения буровых работ. Включает как поломки аппаратуры, так и технологические/организационные задержки: ожидание оборудования, длительные замеры, дефекты резьбы, слом оборудования сторонними службами, сильные гидропомехи промывочной жидкости.
   - Определяется наличием самой записи в таблице `НПВ APS`.
2. **Отказ оборудования (Failure)**:
   - Флаг `fldCRTr2ynwQSJPFI = true`.
   - Включает случаи отказа телесистем (ТС), пульсаторов, датчиков, резистивиметров, разрушения элементов APS.
   - Из 496 инцидентов отказами помечены **270** (54.4%). Остальные **226** — инциденты НПВ без отказа оборудования.

## 9. Находки, риски и расхождения

1. **Критичность: Высокая — Единица измерения времени `fldIacwb7vB0hEzKi`**:
   - *Файл/поле*: `fldIacwb7vB0hEzKi` («Время НПВ, ч») имеет тип `duration`. В Airtable API и реплике длительность хранится в **секундах** (например, `8100` = 2.25 ч, `84600` = 23.5 ч).
   - *Последствие*: Прямое суммирование без деления на `3600` завысит показатели в 3600 раз.
   - *Решение*: Использовать формульное поле `fldyEYf5Y8Ipj7Nke` (где уже выполнено `/3600`) либо применять нормализацию `numeric(val) / 3600` аналогично `TripsDashboard.jsx:21`.
2. **Критичность: Средняя — Отсутствие прямой циркуляции в самой таблице НПВ**:
   - *Файл*: `tblphX6hWZYGT57s3` не хранит часы наработки/циркуляции рейса, только ссылку на рейс `fldyIFYBWtOi2lRh0`.
   - *Последствие*: Расчёт удельного НПВ (на 100 ч циркуляции) требует сквозного объединения с таблицей `Рейсы APS`. При автономном отображении только записей `НПВ APS` этот показатель не может быть вычислен без загрузки связей рейсов.
   - *Решение*: Для базового дашборда НПВ сделать удельную циркуляцию опциональной либо передавать строки рейсов в контекст дашборда.
3. **Критичность: Средняя — Пустые значения в полях `Время НПВ`**:
   - Из 496 записей у 55 поле длительности не заполнено (NULL).
   - *Последствие*: Риск искажения средних значений при делении на общее число записей.
   - *Решение*: Чётко разделять счетчики: «Всего инцидентов» (496) и «Инцидентов с рассчитанным временем» (441), в деталях указывать количество заполненных строк.
