## Находки

### Находка 1 — Тест ссылается на несуществующий фильтр «Рейтинг APS от» (критично: средне)
- **Файл/строки:** `web/src/pages/PersonnelDashboard.test.jsx:24`, `web/src/pages/PersonnelDashboard.jsx`
- **Описание:** Тест ожидает поле ввода с `aria-label="Рейтинг APS от"`, но в компоненте `PersonnelDashboard.jsx` такого поля нет. В компоненте есть только: поиск по ФИО, селект метрики (Рейсы/Работы), кнопка «Печать / PDF», кнопка показа/скрытия справочника.
- **Воспроизведение:** `npx vitest run src/pages/PersonnelDashboard.test.jsx` → ошибка на строке 24 (`getByLabelText('Рейтинг APS от')` не находит элемент), каскадно падает строка 25 (`0 сотрудников`).
- **Последствия:** 2 из 187 тестов не проходят. Тест описывает поведение (фильтрация по минимальному рейтингу), которого нет в текущей реализации компонента.
- **Примечание:** по границе задачи тесты не редактировать. Находка задокументирована для следующего шага.

### Находка 2 — Нет браузера для браузерной проверки (критично: средне)
- **Описание:** Задание требует проверить в браузере три дашборда: фильтры, поиск, пустые данные, печать/PDF. В окружении нет браузера.
- **Непроверенные пункты:** поиск по ФИО (визуально), отсутствие фильтрации по статусу у Персонала, скрытая строка параметров печати, секунды/часы rollup у Рейсов, печать/PDF во всех трёх дашбордах.
- **Последствия:** браузерная часть аудита не выполнена.

### Находка 3 — Большой JS-чанк в сборке (критично: низко)
- **Файл:** `web/dist/assets/index-C63blpJD.js` — 747.72 кБ (превышает 500 кБ порог Rollup).
