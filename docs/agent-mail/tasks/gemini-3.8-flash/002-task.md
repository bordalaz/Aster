# Задание 002 — уточнение требований НПВ

Отчёт 001 принят как предварительный анализ, но не как готовая спецификация. Исправь следующие противоречия в новом отчёте; исходный отчёт сохраняй.

1. Убери ошибочное «нерукотворное». Расшифровку НПВ обоснуй источником либо отметь как требующую подтверждения.
2. Средняя длительность: сумма известных длительностей / количество известных длительностей, включая реальные нули. Не делить на все инциденты при пропусках. Не называть MTTR без подтверждённого определения времени восстановления.
3. Наличие вложения не доказывает наличие акта расследования. Отсутствие причин не доказывает незавершённое расследование. Используй буквальные названия: «есть вложения», «причины не указаны».
4. MTBF и удельные показатели отложи до определения полной выборки рейсов, периода экспозиции и единиц. Учти рейсы без инцидентов и дедупликацию рейсов при нескольких инцидентах. Не предлагай считать знаменатель только по рейсам с НПВ.
5. Группы причин и значения checkbox: отличи фактическую схему от предложенной классификации. Не трактуй отсутствие флага как доказанную организационную причину. Проверь кардинальность связей по данным, не выводи её из одного типа multipleRecordLinks.
6. Дай воспроизводимый расчёт количества записей, заполненных/пустых/нулевых длительностей, суммы и среднего по снимку. Укажи дату снимка, если установима; не выдавай его за актуальную production-базу.

Результат: минимальная спецификация первой версии — число инцидентов, число отмеченных отказов, известные часы НПВ, средняя известная длительность, полнота данных, динамика и причины. Для каждой метрики источник, формула, поведение при пустой выборке. Остальные предложения отдельно.
