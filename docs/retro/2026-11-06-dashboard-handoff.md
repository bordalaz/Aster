## Публикация на сервер

Команду запускает пользователь в PowerShell, потому что `sudo` требует его пароль:

```powershell
ssh -t -i C:\Users\Denis\.ssh\id_ed25519 -o IdentitiesOnly=yes -p 2222 aster-su@192.168.1.57 "sudo rsync -a ~/aster/web/dist/ /srv/aster/"
```

Отсутствие вывода после ввода пароля обычно нормально для `rsync`. Проверить публикацию можно сравнением `~/aster/web/dist/index.html` и `/srv/aster/index.html` по SSH.
