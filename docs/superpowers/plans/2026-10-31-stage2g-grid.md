# Этап 2г — сетка: группировка, итоги, выгрузка, вставка (spec R9)

- **Группировка** по одной колонке (`config.group` вида): заголовок группы «▾ Брак · 66», щелчок сворачивает. Группы по названию, пустые («—») в конце; внутри — сортировка вида.
- **Итоги** — закреплённая нижняя строка: числа — сумма с точностью поля, остальное — «заполнено N». По отфильтрованным строкам. `ponytail:` вид итога (среднее/мин/макс) не выбирается.
- **Выгрузка CSV для Excel**: видимые колонки и строки текущего вида; «;» + BOM — русский Excel открывает без мастера; дробная часть — запятая. E19: текст, начинающийся с `= + - @`, выгружается с апострофом. `ponytail:` настоящий .xlsx — если CSV не устроит.
- **Вставка из Excel**: диапазон раскладывается по ячейкам (`onPaste`), числа «1 234,5», галочки «да/ИСТИНА». Несколько ячеек — один пакет `PATCH /api/tables/{t}/records` (до 1000 записей, всё или ничего, история по каждой). Нередактируемые поля и строки групп/итогов пропускаются.
- **Пересчёт формул склеивается**: правки во время расчёта дают один следующий расчёт, а не по одному на правку.
