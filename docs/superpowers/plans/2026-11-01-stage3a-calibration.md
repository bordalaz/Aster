# Этап 3а — калибровка (spec R22–R26, R20, E11, E13, E14)

В Airtable калибровок как сущности нет (только упоминания в тексте «Вид работ» ремонтов) — переносить нечего,
журнал калибровок начинается с нуля.

- Тип прибора — по номенклатуре (ссылка Оборудование → Номенклатура, поле «Наименование»):
  «МИР» — МИР; «Кожух резистивиметра …» — кожух; «Инклинометр», «Гамма-зонд», «…резистивиметр…» (не кожух) —
  одиночные приборы (R23: только дата). Номер — «Серийный номер», иначе цифры из названия прибора.
- Списанные и оставленные в скважине в выборе не показываются (E11).
- `app_calibration` (дата, прибор, кожух — только у МИРа, примечание, кто, ключ отправки E6).
  Файлы — в общей таблице вложений (`table_id = 'app_calibration'`), видят все, кто видит Оборудование.
- Файлы переименовываются (R25): `МИР-099_КОЖУХ-145_4.75_2026-08-23.<расширение>`; номер — с ведущими нулями до 3;
  совпадение имени (та же пара в тот же день, E13, или два файла одного типа) — `_2`, `_3`…;
  исходное имя хранится в `attachment.original_name`.
- Габарит кожуха — из названия номенклатуры по таблице `app_housing_size` (121/130 → 4.75; 166/181 → 6.75;
  190/213 → 8). Неизвестный — имя без габарита и подсказка админу (E14), админ добавляет габарит тут же.
- API `/api/calibration/…`: приборы для формы, запись калибровки, калибровки прибора (карточки МИРа и кожуха),
  матрица МИР × кожух (последняя совместная калибровка; R24).
- Веб: экран «Калибровка» — форма и матрица (цвет по R20: срок — год; ≤ 5 дней — оранжевый, прошёл — красный);
  в карточке прибора Оборудования — блок «Калибровки».
- Не в этом PR: колонки калибровки в сетке Оборудования (R21) и справка (R29).
