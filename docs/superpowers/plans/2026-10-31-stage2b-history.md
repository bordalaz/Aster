# Этап 2б — история изменений (spec R11)

**Что:** у каждой записи — кто, когда, какое поле, было → стало. Основа для A2 (правка «от системы»).

- `app_change` (миграция 0005): таблица, запись, колонка, `old`/`new` в jsonb, `user_id` (null = «система»), время. Индекс (таблица, запись, время).
- PATCH: старые значения правимых колонок читаются `select … for update` в той же транзакции; новые — из `update … returning`. Обе стороны через `to_jsonb`, поэтому даты и числа хранятся так, как их отдаёт БД. Пишутся только реально изменённые поля. Неудачная правка (409/422/403) ничего не пишет.
- `GET /api/tables/{t}/records/{r}/history`: новые сверху; подпись поля из `app_field`, имя пользователя или «система»; права — как у чтения таблицы (чужая — 404).
- Карточка: блок «История изменений», значения — через тот же показ, что в сетке. Перечитывается при новой версии записи. Без прав на правку нет кнопки «Сохранить».

**Не вошло:** история создания и удаления записей (их ещё нет — формы, этап 2в). История вычисляемых полей не пишется: они следуют из сырых.
