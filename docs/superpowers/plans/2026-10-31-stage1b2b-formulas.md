# Этап 1б-2b — формулы Airtable и сверка с at_computed

**Цель:** вычислять все 93 formula-поля и 3 отложенных rollup («последнее/первое значение»), значение каждой записи сверять с `at_computed`.

**Решение:** формулы считаются на Python, как агрегаты в 1б-2a: разбор формулы в дерево и вычисление по нему. Семантику Airtable (BLANK, JS-числа, локаль, форматы дат) держим в одном месте — `api/migrate/formula.py`. SQL-представления из дизайна §77 при необходимости строятся позже из того же дерева (этап 1в).

**Сверка изолированная:** входы формулы берём через `compute._field_values` — колонка, `at_computed` (для вычисляемых входов) или связь. Ошибка в одной формуле не тянется по цепочке. Пересчёт по цепочке (формула от формулы от rollup) — задача приложения, этап 1в.

## Что используется в базе (инвентаризация 2026-10-31)

Операторы: `& + - * / = > `; функции: `BLANK IF DATETIME_FORMAT YEAR SET_LOCALE CONCATENATE MONTH DATETIME_DIFF TODAY NOW SWITCH ROUNDUP LEFT OR`. Форматы дат: `DD MM YYYY YY MMMM GGGG`.

Семантика, снятая с `at_computed`:
- числа по правилам JS: `x/0` → `{"specialValue":"Infinity"}`, `0/0` и `YEAR(пусто)` → `NaN`; в строке NaN — `"NaN"` (`Работы.Год + месяц` = `"NaN NaN"`);
- `SET_LOCALE(d,'ru')` + `MMMM` → «Январь» (именительный падеж, с заглавной);
- `TODAY()` = дата снимка (`Оборудование.Номер справки` = `3110/26`);
- `DATETIME_DIFF('08-01-2023','12-31-2020','month')` = 31: строки вида MM-DD-YYYY, разница — целые месяцы.

## Задачи

1. `formula.py`: токенизатор и парсер (приоритеты: сравнения < `&` < `+ -` < `* /` < унарный минус) → дерево. Тесты: разбор каждой реальной формулы без ошибок.
2. Вычислитель: значения None/число/строка/дата/список, функции из списка выше. Тесты на мини-случаях семантики (BLANK, JS-деление, `&` с числами и списками, даты, SWITCH, ROUNDUP).
3. Отложенные rollup: функции `LAST` (ARRAYJOIN через `;`, хвостовая `;` отрезается, берётся последний элемент) и `FIRST` (ARRAYJOIN, текст до первой запятой) в `rollup_aggs` и `compute._aggregate`.
4. `verify_formulas` + `compute-verify` считает и формулы; относительный допуск для чисел.
5. Боевая сверка, разбор хвоста расхождений, отчёт `docs/2026-10-31-formulas-run.md`.
