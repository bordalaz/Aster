# Этап 2в — виды (spec R9 частично, R10)

**Что:** сохранённые наборы «колонки + ширины + сортировка + фильтры» для сетки; общие (создают админы) и личные (любой вошедший). Виды Airtable переносятся.

## Что даёт Airtable
Публичный API отдаёт у вида только `id`, `name`, `type` и — для grid, с `include=visibleFieldIds` — видимые колонки в порядке показа. **Фильтров, сортировок и группировок в API нет.** Проверено 2026-10-31: 231 вид, 175 grid с колонками, личных нет.

→ Переносим 175 grid-видов как общие: название, порядок и набор колонок. Остальные типы (kanban, calendar, gallery, timeline, form, block) — вне v1. Импортированный вид помечен `source: "airtable"`; пока у него нет своих фильтров и сортировок, сетка предупреждает: «фильтры и сортировка из Airtable не переносятся — задайте и сохраните». Восстановить их можно вручную или по скриншотам, как rollup. *(Обновлено 2026-11-01: фильтры, сортировки и группировки сняты из веб-клиента Airtable — см. `2026-11-01-stage2d-airtable-filters.md`; подсказка убрана.)*

## API
- `GET /api/tables/{t}/views` — общие и свои личные; доступ — как чтение таблицы.
- `POST /api/tables/{t}/views` {title, shared, config}; общий — только админы.
- `PATCH/DELETE /api/views/{id}` — личный правит владелец, общий — админы.
- `config` строго по схеме (лишнее → 422): `columns` (видимые по порядку), `widths`, `sort` [{col, desc}], `filters` [{col, op, value}], `source`. Колонки — только из полей таблицы.
- Фильтры и сортировка применяются в браузере (все строки уже там). `ponytail:` — на сервер, если перейдём на постраничную загрузку.

## Перенос
`python -m migrate views`: схема с `include=visibleFieldIds` → `/data/snapshot/views.json` → `app_view` (upsert по `airtable_id`, колонки — через `app_field.airtable_id`). `load` тоже подхватывает `views.json`, если он есть.

## Веб
Над сеткой: выбор вида, «Колонки» (показать/скрыть, порядок; перетаскивание в шапке), «Фильтры» (поле, условие, значение), сортировка кликом по шапке; «Сохранить», «Сохранить как…» (галочка «общий» — админам), «Удалить». Несохранённые изменения отмечены.
