## Вывод (предложение)

Отрисовка — **Glide Data Grid** (MIT): в 4–8 раз быстрее на прокрутке, а правка, вставка и выделение уже есть.
Логика строк (фильтры, сортировка, группировка) — функции TanStack Table без его отрисовки. Glide получает готовый список строк, где строки-заголовки групп вставлены отдельными записями.
Минус canvas: на телефоне и для экранных дикторов сетка хуже. Карточку записи и формы делаем обычным DOM, телефон — через них (В4).

## Группировка поверх Glide (проверено 2026-10-28)

`src/GlideGrid.jsx`: поиск, сортировку и группировку считает `useReactTable` (TanStack), Glide только рисует `table.getRowModel().rows`. Строка группы — ячейка на всю ширину (`span`) с подсветкой (`getRowThemeOverride`), клик раскрывает или сворачивает группу.

- Включение группировки: 26 мс; 5 групп по 2716 строк.
- Прокрутка раскрытой группы: медиана 3,5 мс, худшие 5% — 7,0 мс. Скорость та же, что без группировки.
- Сортировка внутри групп работает. Правка ячейки внутри группы пишет в нужную запись: VZ-1, Кол-во → 999.
- Поиск стал медленнее: 108 мс вместо 38, потому что глобальный фильтр TanStack проверяет все колонки. Терпимо. Если станет мешать — свой фильтр или поиск на сервере.
- Подтверждение правки клавишей Enter автоматикой проверить не удалось: значение сохранилось только при уходе из ячейки. Проверить руками.
- Мелочи на потом: номера строк слева считают и строки групп; клик по строке группы выделяет ячейку.

Вывод подтверждён: Glide для отрисовки, TanStack для логики строк.

Не проверено: отрисовка ячеек select/связь/вложение, вложенная группировка (2+ уровня), реальные данные.
