# HTTPS в локальной сети: «Подключение не является приватным»

Сервер в локалке (`ASTER_TLS=internal`) шифрует связь сертификатом своего центра сертификации Caddy
(«Caddy Local Authority», корневой сертификат действует до 2036 г.). Браузеры этот центр не знают —
отсюда `NET::ERR_CERT_AUTHORITY_INVALID`.

**Что сделать на каждом компьютере и телефоне (один раз):** открыть `http://<ASTER_HOST>/trust`
(по обычному http — без предупреждения), скачать сертификат, сверить отпечаток SHA-256 и поставить
в доверенные корневые — там пошаговая инструкция для Windows, Android, iPhone.

Страницу и сертификат раскладывает `ops/deploy.sh` (в `/srv/aster-trust`), отдаёт Caddy (`http://` в
`ops/Caddyfile`); всё остальное по http уходит на https. Ключ центра остаётся на сервере
(`/var/lib/caddy/.local/share/caddy/pki/authorities/local/`, только у пользователя caddy) — без него
сертификат подделать нельзя. Если папку данных Caddy удалить, он создаст новый центр — сертификат
придётся ставить заново.

**Когда появится домен и белый IP:** `ASTER_HOST=<домен>`, `ASTER_TLS=<e-mail>` в `.env`, `sh ops/deploy.sh` —
настоящий сертификат Let's Encrypt, ставить ничего не нужно.
